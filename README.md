# Phishing Awareness Training

**CodeAlpha Cybersecurity Internship – Project 2**

## Project Overview

Phishing is a social engineering attack in which cybercriminals impersonate trusted individuals or organisations to trick users into revealing sensitive information or performing unsafe actions.

This project provides cybersecurity awareness training through interactive lessons, practical demonstrations and assessments.

## Project Objectives

- Explain phishing and common phishing techniques.
- Identify suspicious emails and fraudulent websites.
- Understand social engineering attacks.
- Learn how to protect accounts and sensitive information.
- Understand how to report and respond to phishing incidents.

## Project Features

### 1. Interactive Learning Modules
Six lessons covering:
- Understanding Phishing
- Types of Phishing
- Social Engineering
- Detecting Fake Websites
- Protection Strategies
- Incident Response

### 2. Practical Demonstrations
- Analyse a fictional suspicious email.
- Inspect a suspicious URL.
- Identify common phishing warning signs.

### 3. Interactive Quiz
A five-question assessment with immediate feedback and explanations.

### 4. Certificate Generation
Participants who achieve at least 80% can generate a certificate of completion.

## How to Run

1. Download or clone this repository.
2. Open the `Online_Module` folder.
3. Open `index.html` in a web browser.
4. Explore the lessons and practical exercises.
5. Complete the quiz.
6. Achieve at least 80% to generate your certificate.

## Safety Notice

This project is intended strictly for cybersecurity education. All practical examples are fictional. The project does not collect passwords or target real individuals or organisations.
